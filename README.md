## Key Features & Pages
1. **Dynamic Real-Time Store Status**: Automatically calculates whether the shop is Open, Closing Soon, or Closed based on Ohio Eastern Time.
2. **Interactive Husbandry Engine**: Select species (Bearded Dragon, Crested Gecko, Leopard Gecko, Ball Python, Axolotl, Chameleon) to instantly view thermal gradients, humidity targets, UVB lighting requirements, and diet cadences.
3. **Weekly Feeder & Schedule Calculator**: Dynamic calculator for keepers to plan monthly insect and rodent restocks.
4. **Live Square Store Catalog**: Seamlessly connected to official Square Online product and category checkout pages.
5. **Interactive Inquiry & Consultation Portal**: Direct messaging modal for species availability and custom bioactive terrarium quotes.
6. **Plan Your Visit & Interactive Google Map**: Embedded map, parking directions, and first-time keeper visit checklist.
7. **Transparent Welfare Policies**: Detailed animal welfare vetting, In-Store Pickup policy (no shipping), all sales final terms, and 4-installment AfterPay financing.

---

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom glassmorphism, terrarium color system, and glow utilities
- **Icons**: Lucide React
- **Web Server**: Multi-stage Caddy container with compression, security headers, and static fallback routing

---

## Development & Build Commands

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle & static entry points
npm run build

# Preview production build locally
npm run preview
```
